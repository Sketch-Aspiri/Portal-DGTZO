La verificación en dos pasos protege tu cuenta: además de la contraseña pide un código que genera tu celular. Es **obligatoria** para quienes aprueban cuentas y opcional para los demás.

## Instala una aplicación de autenticación

En tu celular instala una de estas: Google Authenticator, Microsoft Authenticator o Authy.

## Escanea el código

Si es obligatoria para ti, esta pantalla aparece al iniciar sesión. Si no, ábrela desde **Mi perfil → Activar verificación en dos pasos**.

En la aplicación del celular elige agregar una cuenta y escanea el código QR. Si no puedes escanearlo, escribe a mano la clave que aparece debajo.

![Pantalla de activación con el código QR](01-configurar.png)

## Confirma con el código

1. Escribe el código de 6 dígitos que muestra la aplicación.
2. Toca **Confirmar y activar**.

![Campo del código y botón Confirmar y activar](02-codigo.png)

El código cambia cada 30 segundos. Si lo rechaza, espera al siguiente y revisa que la hora del celular sea automática.

## Guarda tus códigos de recuperación

> Se muestran **una sola vez**. Guárdalos en un lugar seguro, fuera del celular. Cada uno sirve una vez.

![Lista de códigos de recuperación de ejemplo](03-recuperacion.png)

## Cada vez que entres

Después de tu contraseña, escribe el código actual de la aplicación y toca **Verificar**. Si no tienes el celular, abre **Usar un código de recuperación** y escribe uno de los que guardaste.

![Pantalla de verificación al iniciar sesión](04-al-entrar.png)

Si perdiste el celular y no tienes códigos de recuperación, avisa a la Zona.
